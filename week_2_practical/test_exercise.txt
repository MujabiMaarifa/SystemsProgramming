//Answer 1
Systems programming simply refers to the writing software that provides services to the hardware and the software running the computer.
Application programming focuses on creating software for users.

Differences
Application Programming
- High level of abstraction
- Languages: Python, JS, Java
- Focuses on the USer hence user interface
- Indirect hardware access
- Needs moderate performance
- Word, browser

Systems Programming
- Low level of abstraction
- Languages: C, C++, Rust -> low level programming languages
- Direct hardware access
- Needs very efjficient performance
- compiler, OS, Driver

- Has minimal runtime overhead

- C has low level memory manipulation
